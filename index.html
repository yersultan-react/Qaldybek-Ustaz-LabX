Теориялық түсінік

Еркін электромагниттік тербеліс — тізбекте бастапқы энергия берілгеннен кейін сыртқы әсерсіз жүретін тербеліс.

Идеал LC контурында:

ω₀ = 1 / √(LC)
T = 2π√(LC)

Заряд пен ток периодты түрде өзгереді, энергия электр және магнит өрістері арасында ауысады.

Электр өрісінің энергиясы:

Wₑ = q² / (2C)

Магнит өрісінің энергиясы:

Wₘ = LI² / 2

Толық энергия сақталады:

W = Wₑ + Wₘ = q₀² / (2C) = const

Еріксіз электромагниттік тербеліс — тізбекке периодты сыртқы ЭҚК әсер еткенде туатын тербеліс.

Сыртқы жиілік меншікті жиілікке жуықтағанда резонанс байқалады.

E(t) = E₀ · sin(ωt)

Зертханалық тапсырмалар

01L және C мәндерін өзгертіп, меншікті жиіліктің қалай өзгеретінін бақыла.
02R кедергісін арттырып, еркін тербелістің бәсеңдеуін зертте.
03Еріксіз режимге өтіп, сыртқы жиілікті өзгертіп, резонанс аймағын тап.
04Резонанс кезінде ток амплитудасының неге өсетінін түсіндір.
05LC және RLC тізбектерінің айырмашылығын қорытындыла.
